A reconstruction. The original console was a Flask template reading a SQLite table that an OpenCV loop wrote to, on one laptop in a hackathon hall. That HTML is lost, so this rebuilds the same surface as a single static page: the matcher runs here in the browser against a simulated room, drawing its distances from the two distributions the real one produced. Every number on this page comes from that simulation and not from a recorded class. The threshold, the deduplication rule, and the shape of the register are the parts that were real.
